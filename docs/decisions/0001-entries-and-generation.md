# ADR 0001: 人が書くのはセッションごとのメモ、日報は自動生成

- 状態: 採用
- 日付: 2026-11-10

## 背景

手書きの日報は書き忘れやすく、1日1ファイルを複数の PR が編集すると衝突する。コミット一覧のように Git から取れる情報を人が写すのは無駄。

## 選択肢

| 案 | 内容 | 欠点 |
| --- | --- | --- |
| A 1日1ファイルを手で書く | `docs/log/日付.md` を直接編集 | 書き忘れ、並行 PR で衝突、コミット一覧の写し間違い |
| **B メモ＋自動生成** | セッションごとのメモ（`docs/log/entries/日付/時刻-件名.md`）と Git 履歴から日報を生成 | 生成ツールの保守が要る |
| C Git 履歴だけ | コミットとPRだけで日報を作る | 決めたこと・次にやることが残らない |

## 決定

案Bを採用する。日報と一覧は毎回作り直し、出力は決定的にする（生成時刻を入れない）。メモの見出しは「決めたこと／作ったもの・変えたもの／次にやること／未解決・判断待ち」の4つ。

## 影響

日報ファイルの手修正は次の生成で消える。直したい内容はメモに書く。
