# ADR 0003: 配布は一時的な worktree で作業し、PR にする

- 状態: 採用
- 日付: 2026-11-10

## 背景

導入・更新の対象は利用者の作業中のリポジトリ。未コミットの変更や作業中のブランチ、LFS の素材を壊してはならない。main への直接 push は取り消しにくい。

## 選択肢

| 案 | 内容 | 欠点 |
| --- | --- | --- |
| A 作業フォルダで直接コミット | 簡単 | 作業中の変更と混ざる。今のブランチが変わる |
| **B 一時的な worktree＋PR** | origin の既定ブランチから worktree を作り、ブランチ `chore/daily-log-v<版>` にコミットして PR | 処理がやや長い |

## 決定

案Bを採用する。既定は確認のみ（`-Apply` で実行）。LFS はダウンロードしない。キット自身は対象外。push 後は手元の作業用ブランチを消す。版ごとにブランチ名を変え、前回のブランチが残っていても次の版を配れるようにする。

## 影響

マージは利用者が GitHub で行う。PR を閉じれば何も変わらない。
