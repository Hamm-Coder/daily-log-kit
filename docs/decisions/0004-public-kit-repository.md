# ADR 0004: キットのリポジトリは公開にする

- 状態: 採用
- 日付: 2026-11-10

## 背景

Web 版 Claude Code から各リポジトリのセッションでキットを取得したい。GitHub App で接続したセッションは、公開リポジトリならどれでも読めるが、非公開は App を入れたものだけ。

## 選択肢

| 案 | 利点 | 欠点 |
| --- | --- | --- |
| **A 公開** | 設定なしで読める | 中身が誰でも見える（秘密情報は含まない） |
| B 非公開 | 非公開 | キットのリポジトリにも GitHub App を入れる必要がある |

## 決定

案Aを採用する。キットには秘密情報・日報の本体を入れない（日報は各リポジトリ側）。

## 影響

キットに個人情報や作品の設定を入れない。v1.1.2 までは RPGMZ_Prototype 用の `extras/`（世界設定の要約、公開方針を含む日報メモ、ADR）を同梱していたが、反映が済んだため v1.2.0 で削除した。過去の版の履歴（コミットとタグ）には残るので、完全に消す必要があれば履歴の書き換えか、リポジトリの作り直しが要る（利用者が判断する）。特定のリポジトリ向けのファイルは、今後はそのリポジトリの PR に直接入れる。
