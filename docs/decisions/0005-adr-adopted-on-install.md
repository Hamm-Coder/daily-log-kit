# ADR 0005: 導入時に作る ADR は最初から「採用」

- 状態: 採用
- 日付: 2026-11-13

## 背景

RPGMZ_Prototype では日報の ADR を「提案」で入れ、後から「採用」に直す手間が出た。導入 PR のマージ自体が採用の決定であり、閉じれば ADR も入らない。

## 選択肢

| 案 | 欠点 |
| --- | --- |
| A 「提案」で作る | 採用後に直す手間。直し忘れると Claude が日報を任意の作業と扱う |
| **B 「採用」で作る** | PR を確認せずにマージすると、内容を読まずに採用したことになる |

## 決定

案Bを採用する。`docs/decisions/` があるリポジトリだけに作り、日報の ADR が既にあれば作らない。`-NoAdr` で作らない。

## 影響

ADR の本文に「このPRのマージをもって採用とする」と書く。
