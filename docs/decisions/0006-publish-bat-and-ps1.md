# ADR 0006: 反映用のスクリプトは .bat（呼び出し1行）＋ .ps1（処理本体）

- 状態: 採用
- 日付: 2026-11-13

## 背景

チャットで作った新しい版の zip を、ダブルクリックでキットのリポジトリに反映したい。処理はキットのフォルダを上書きするので、実行中のスクリプト自身も上書きされる。cmd は .bat を実行中も1行ずつ読み直すため、上書きされると誤動作しうる。PowerShell は最初に全体を読み込む。

## 選択肢

| 案 | 欠点 |
| --- | --- |
| A .bat だけ | 実行中の上書きで誤動作しうる。日本語の扱いが難しい |
| **B .bat（1行）＋ .ps1** | ファイルが2つになる |

## 決定

案Bを採用する。.bat は `( powershell ... & pause & exit /b )` の1行で、括弧の中を一度に読み込ませる。実行ポリシーは .bat の中で `-ExecutionPolicy Bypass` を指定する。.bat は英数字のみ・CRLF（`tests/kit.test.mjs` で検査）。

## 影響

Claude Code がキットのリポジトリを直接直す場合は zip を使わず、PR のマージと `kit-release.yml` でタグを作る。
