# ADR 0007: 分析は傾向の目安に限り、成果の評価に使わない

- 状態: 採用
- 日付: 2026-11-13

## 背景

日報と Git の履歴から数値を出せるようになった。一方で、活動量の指標（コミット数など）だけで生産性を判断すると、指標を増やすこと自体が目的になり、作業全体が損なわれることが知られている（SPACE フレームワーク、Forsgren et al. 2021）。

## 選択肢

| 案 | 欠点 |
| --- | --- |
| A スコア化（点数・ランキング） | 件数を増やす行動を招く。個人開発では比較相手もいない |
| **B 傾向と「確認のきっかけ」だけを出す** | 一目での良し悪しはわからない |

## 決定

案Bを採用する。改善点は根拠の数値と次の行動を1つずつ出し、理由があれば対応しなくてよいと明記する。根拠のあるしきい値（深夜0〜4時: Eyolfson et al. 2011）は出典を添える。

## 影響

将来、量以外の観点（手応え、詰まったこと）を任意で記録する（SPEC M4）。
