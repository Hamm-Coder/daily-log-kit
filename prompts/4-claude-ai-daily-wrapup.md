# 依頼文4: claude.ai のチャットの最後に、その日の日報メモを出してもらう

チャットで設定や方針を決めた日の最後に貼り付けます。

---

今日のこのチャットの内容を、日報メモの形式で1ファイルにしてください。

- パス: `docs/log/entries/<今日の日付>/<今の時刻HHMM>-chat-<件名の英字>.md`
- frontmatter: date、time、source: chat、branch: chat、title
- 見出し: 決めたこと／作ったもの・変えたもの／次にやること／未解決・判断待ち
- 「決めたこと」は私が決めた・承認したことだけ。あなたの提案で未承認のものは「未解決・判断待ち」へ
- 以前の判断待ちをこのチャットで決めたときは、「決めたこと」に `解決: <判断待ちの項目> → <決めた内容>` と書く
- 作った設定書や ADR は、ファイル名と版番号を書く

---

出てきたファイルは、Claude Code に「このファイルを日報メモとして追加してPRにして」と渡します（作業中のPRがあれば、そのPRに含めてもらいます）。
